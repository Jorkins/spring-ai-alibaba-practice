# 第 02 篇：5 分钟搭建第一个 Spring AI Alibaba 应用

## 代码结构

```
spring-ai-hello/
├── pom.xml
├── src/main/java/com/example/ai/HelloAiApplication.java
└── src/main/resources/application.yml
```

## 快速开始

1. 获取阿里云 DashScope API Key（https://help.aliyun.com/zh/dashscope/）
2. 设置环境变量：
   ```bash
   export AI_DASHSCOPE_API_KEY=你的-api-key
   ```
3. 运行：
   ```bash
   ./mvnw spring-boot:run
   ```
4. 查看控制台输出的 AI 回答

正文请参考公众号推送《Spring AI Alibaba 实战 02：5 分钟搭建第一个 Java AI 应用》。
